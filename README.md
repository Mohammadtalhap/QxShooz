# 🛍️ QxShooz - Modern E-Commerce Shoe Store

A responsive e-commerce web app built with React, Vite, and Tailwind CSS. This project focuses on a clean UI, product browsing, search, wishlist, and cart experience.

## ✨ Key Features

- Responsive home page with promotional banners and sliders
- Product catalog with search and filtering
- Wishlist and cart functionality
- Persistent cart and wishlist state using localStorage
- Modern UI built with Tailwind CSS
- Smooth navigation across pages

- React
- Vite
- React Router DOM
- Tailwind CSS
- Swiper
- Lucide React / React Icons

## ▶️ How to Run

### 1. Install dependencies
```bash
npm install
```

### 2. Start the development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
